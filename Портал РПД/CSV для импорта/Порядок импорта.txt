Импорт демонстрационных данных портала РПД

Файлы CSV в UTF-8, разделитель — запятая, первая строка — названия полей. Пустые teacher_comment и chair_comment означают SQL NULL. Учётная запись преподавателя и заявки — демонстрационные.

Сначала импортируйте rpd.sql в отдельную свежую установку. SQL добавит справочник дисциплин и администратора. Затем запустите import.php. Скрипт сверит справочник, сохранит существующий пароль Admin, импортирует остальные строки в порядке зависимостей и положит два документа в хранилище РПД.

Порядок таблиц на чистой схеме без начальных записей
1. disciplines.csv
2. users.csv
3. teacher_disciplines.csv
4. applications.csv

Команды для РЕД ОС из каталога «Портал РПД»
sudo -u daemon env RPD_STORAGE=/opt/lampp/rpd-storage /opt/lampp/bin/php 'CSV для импорта/import.php'

Используйте фактического пользователя Apache вместо daemon, если он отличается. Если у базы есть пароль или отдельная учётная запись, передайте параметры RPD_DB_USER и RPD_DB_PASSWORD. Для другого хоста или порта используйте RPD_DB_HOST и RPD_DB_PORT.

Вход для проверки
Администратор — Admin / KorokNET.
Преподаватель — DemoTeacher / DemoRPD2026.

Для обычной установки достаточно rpd.sql. Импорт демонстрационных заявок нужен для проверки на пустой установке.
