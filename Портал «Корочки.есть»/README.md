[Установка в РЕД ОС и XAMPP](../Запуск%20в%20РЕД%20ОС.txt)

Статусы «Новая», «В обработке» и «Выполнена» соответствуют прежним идентификаторам 1, 2 и 3. Старые заявки сохраняются. Отзыв может отправить владелец заявки после завершения обучения.

В новой базе уникальность почты обеспечивается и приложением, и ограничением SQL. Для существующей базы приложение проверяет почту и без повторного импорта. Чтобы добавить ограничение в старую базу, сначала проверь дубли почты. Контакт в подвале взят из демонстрационной учётной записи.
