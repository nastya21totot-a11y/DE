Основная инструкция — запуск «Корочки.есть» и портала «РПД» в РЕД ОС

Выполняй команды внутри РЕД ОС. Инструкция рассчитана на первую установку двух сайтов с XAMPP в /opt/lampp.

1. Скачай проекты

git clone --depth 1 https://github.com/nastya21totot-a11y/DE.git ~/DE-nastya

Если Git не установлен, установи его командой sudo dnf install git. Без интернета клонируй из доступного локального репозитория в ту же папку ~/DE-nastya.

2. Скопируй сайты в XAMPP

sudo mkdir -p /opt/lampp/htdocs/korochki /opt/lampp/htdocs/rpd
sudo cp -R "$HOME/DE-nastya/Портал «Корочки.есть»/." /opt/lampp/htdocs/korochki/
sudo cp -R "$HOME/DE-nastya/Портал РПД/." /opt/lampp/htdocs/rpd/
sudo install -d -m 0750 -o daemon -g daemon /opt/lampp/rpd-storage

Сохрани кавычки и точку после косой черты, чтобы скопировать .htaccess. Перед копированием проверь, свободны ли папки назначения. Если там уже есть сайт, используй отдельные папки и подставь их имена в командах импорта и адресах. Если в /opt/lampp/etc/httpd.conf указаны другие User и Group, подставь их вместо daemon в команде создания хранилища РПД.

3. Запусти XAMPP и импортируй базы

sudo /opt/lampp/lampp start
/opt/lampp/bin/mysqladmin -u root ping

Дождись ответа «mysqld is alive». Если база уже содержит рабочие данные, пропусти её импорт.

/opt/lampp/bin/mysql --default-character-set=utf8mb4 -u root < /opt/lampp/htdocs/korochki/korochki_db.sql
/opt/lampp/bin/mysql --default-character-set=utf8mb4 -u root < /opt/lampp/htdocs/rpd/rpd.sql

4. Открой сайты в браузере внутри РЕД ОС

Корочки.есть     http://localhost/korochki/
РПД              http://localhost/rpd/

В начальных базах логин администратора Admin, пароль KorokNET. После перезагрузки достаточно снова выполнить sudo /opt/lampp/lampp start.

При ошибке загрузки PHP «libbz2.so.1.0» на проверенной сборке убедись, что /usr/lib64/libbz2.so.1 существует. Если ссылка XAMPP ещё не создана, выполни sudo ln -s /usr/lib64/libbz2.so.1 /opt/lampp/lib/libbz2.so.1.0.
